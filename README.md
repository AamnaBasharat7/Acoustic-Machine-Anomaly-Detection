# Acoustic Machine Anomaly Detection

## Project Overview

This project focuses on detecting abnormal sounds in industrial machines using machine learning.

The system learns from normal machine sounds and identifies whether a new audio sample is normal or anomalous.

## Dataset

- Dataset: DCASE 2020 Task 2
- Machine Type: Fan
- Machine ID: id_00
- Source: https://zenodo.org/records/3678171

## Technologies Used

- Python
- Librosa
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- Joblib

## Machine Learning Models

1. One-Class Support Vector Machine (One-Class SVM)
2. Isolation Forest

## Project Structure

- App: Streamlit application, feature extraction and saved models.
- Notebooks: Model training and evaluation notebooks.
- Results: Evaluation results, graphs and comparison tables.
- Report: Complete project report.

## Application

The application allows users to upload an audio file and receive a prediction indicating whether the sound is normal or anomalous.
